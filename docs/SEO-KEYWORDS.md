## GEO / ChatGPT visibility checklist

1. **Allow `OAI-SearchBot`** in `robots.txt` (ChatGPT search citations); GPTBot optional for training.
2. **Static crawlable text** in HTML (summary + FAQ) — not JS-only.
3. **JSON-LD**: `WebSite`, `FAQPage`, `ItemList` for cases.
4. **`llms.txt`** — plain summary for AI crawlers (emerging convention).
5. **Self-contained factual paragraphs**, statistics with sources, Miami-first case names.
6. **hreflang** between EN and ES properties.
7. **Sitemap + canonical** URLs.
